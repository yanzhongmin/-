# 光位 · 拍照搭子

给"不会拍照的人"用的手机网页 App。举着手机对准场景，它告诉你**人站哪儿、摆什么姿势、参数怎么设、怎么拍出氛围感**；按快门之后还能顺手把美颜和调色调好。

全部在手机本地算，**照片不上传**，没有账号，没有后端。

> **已上线**：https://yanzhongmin.github.io/guangwei/

---

## 手机上怎么打开

地址：**https://yanzhongmin.github.io/guangwei/**

- **华为 / 安卓 Chrome、Edge、夸克**：右上菜单 →「添加到主屏幕」，之后像 App 一样全屏打开。
- **iPhone Safari**：分享 →「添加到主屏幕」。
- 相机权限必须允许，否则只能从相册选图分析。

> 手机上必须是 **https** 或 **localhost**，浏览器才给相机权限。所以本地用 `http://192.168.x.x` 是打不开相机的，必须是 Pages 这种 https 地址。

## 有三种用法

### 1. 实时取景（最常用）

打开就在取景。画面上会叠：

- **三分线 / 黄金分割 / 居中** 三套网格（构图页切换）
- **橙色虚线目标框**：人该站的范围；旁边写着「站这里」
- **半透明人形剪影**：真人大小、按你选的身高缩放，而且姿势就是当前选的那个
- **青色框 + 箭头**：人走进画面后，告诉你「往画面右边挪半步」「往前走一点」；站准了就变成绿的「✓」

底下一行：**人该占画面多高 · 手机放多高 · 你该退到几米外**。

> 小提示：先对着空景停一两秒（让 App 记住"这里本来什么都没有"），再让人走进来，青色框和方向提示才准。人一开始就站在画面里，它认不出"谁是刚进来的"，就不会瞎说话——这是故意的。

### 2. 拍一张空景再分析

现场人多、不好意思让人等着摆？先对着空景拍一张（或者从相册选一张同机位的照片），App 会在这张**照片**上标出框和剪影，你照着让人站进去就行。

### 3. 拍完再美化

按快门 → 自动进入编辑页：

- **美颜**：磨皮（保睫毛发丝）、提亮、去油光、气色、肤色统一、拉长腿、瘦脸。默认值已经调好，手滑一下就能改，也可以「归零」。
- **氛围**：8 个调色预设（日系清新 / 胶片暖调 / 电影青橙 / 港风 / 情绪暗调 / 夜景 / 黑白…）+ 强度滑杆
- 顶部：**重拍 / 拍完再调 / 分享 / 保存**

也可以在相册里挑一张旧照片进来调。

### 4. 自拍（单人 / 2–4 人合照 / 自拍杆）

点右下角**翻转**切到前置，整个 App 换成自拍形态：

- 取景框里画的是**头部框**（不是站位框）：头放进去、头顶留一拳的空；2–4 人时按"最矮的站中间最前"排好 2/3/4 个头框，外面再套一个安全区框
- 底部**一句大字**：`脸往左转 30°，皮会透` / `最矮的站中间最前，头都进框` —— 自拍杆拿远了也看得清
- 构图页选**手持（0.6–0.8m）**还是**自拍杆（1.0–1.2m）**
- 姿势页换 10 个自拍姿势（单手举机 / 双手举高 / 歪头贴手 / 比心 / 两人贴脸 / 三人 V 字 / 四人两排…）
- 参数页换成前置 1x、快门不低于 1/60、机位＝眼睛高度
- 左下角**定时器**：关 / 3s / 5s / 10s，按快门中间出现大数字倒数（自拍杆用 5 秒最稳）
- 前置画面是**镜像**的，成片也按镜像存：看到什么就拍到什么

## 四个面板在说什么

| 面板 | 内容 |
|---|---|
| **构图** | 三套构图规则 + 三个候选位置（推荐 / 备选 1 / 备选 2）+ 三条"为什么选这里"+ 人物占比/机位高度/拍摄距离（自拍时换成 手持/自拍杆 + 头部框三条理由） |
| **姿势** | 30 个姿势，按 站姿 / 动态 / 坐姿 / 特写 / 情侣 / 家庭 / 自拍 分类，每个配一句能直接对TA喊的话 |
| **参数** | 10 项：镜头焦段、人像模式、ISO、快门、曝光补偿、白平衡、测光对焦、HDR、机位高度、拍摄距离。每项都写清"为什么"。底部「复制参数」可以拿到系统相机用，「一键套用」直接把调色套到出片上 |
| **氛围** | 8 个调色预设 + 强度 + 三条针对当前场景的氛围建议（例如"找一片树叶贴近镜头当前景""站在树影和阳光交界""穿浅色衣服在深绿背景前特别跳"） |

右上角「人物」里选**今天拍谁**：身高、类型（女生/男生/小朋友/长辈）、今天衣服的主色、几个人。影响剪影造型、框的大小、以及优先挑跟衣服颜色反差大的背景。

## 自己部署（GitHub Pages）

把仓库里这些文件放到一个仓库根目录，Settings → Pages → Source 选 `main` / `(root)`：

```
index.html
manifest.webmanifest
sw.js
css/app.css
js/{app,scene,compose,params,poses,grade,beauty,guide}.js
icons/{icon-192,icon-512,apple-touch-icon,favicon}.png
```

`dev/`、`docs/` 是开发与说明，不上传也能跑（`dev/` 里有测试脚本和截图工具，不需要）。

更新版本后如果手机上还是旧的，因为 service worker 是缓存优先：下拉刷新一次，或者删掉桌面图标重新添加。

## 技术说明（给想改的人）

纯静态、免构建、无依赖。

- `js/scene.js` — 一帧像素 → 亮度/色温/地平线/竖线/纹理/肤色/主色，判断场景类型
- `js/compose.js` — 穷举候选位置打分（三分对齐 / 背景干净 / 光线均匀 / 衣服与背景分离 / 脚不踩底边 / 头不切地平线 / 不被灯杆穿头）
- `js/params.js` — 由场景 + 人身高 + 构图框反推 ISO/快门/EV/焦段/机位/距离
- `js/poses.js` — 参数化人形骨架（FK），20 个姿势，可镜像、可按身高缩放、可换裙/裤、双人/一家三口
- `js/guide.js` — 背景差分找人，算左右/前后偏差，连续 3 帧稳定才说话，认不准就不说话
- `js/beauty.js` — 肤色遮罩 + 保边模糊 + 提亮/去油光/气色/统一，椭圆瘦脸，分段拉伸拉腿
- `js/grade.js` — 8 个调色预设（CSS filter 预览 / canvas 出片，两套走同一组参数，保证预览=成片）
